# Biblioempréstimo

## Sobre o projeto

O Biblioempréstimo é um projeto acadêmico que tem como objetivo desenvolver um sistema para facilitar o gerenciamento de empréstimos e devoluções de livros.

## Objetivo deste repositório

Este repositório foi criado para organizar os arquivos do projeto e aplicar os conceitos de Gerência de Configuração de Software (GCS), utilizando o GitHub para controlar as versões e acompanhar as alterações.

## Funcionalidades previstas

- Cadastro de livros.
- Consulta ao catálogo.
- Registro de empréstimos.
- Registro de devoluções.

## Organização do projeto

- `docs/`: documentos e planejamento.
- `src/`: arquivos do código-fonte.
- `tests/`: arquivos relacionados aos testes.
- `evidencias/`: capturas de tela e registros da atividade.

## Ferramentas utilizadas

- GitHub: armazenamento e colaboração.
- Git: controle de versões.

## Disciplina

Engenharia de Software — Gerência de Configuração de Software.

## Consulta ao catálogo

O sistema permitirá consultar livros e verificar sua disponibilidade.

## Cadastro de livros

O sistema permitirá cadastrar livros com título, autor e editora.
