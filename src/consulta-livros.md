# Consulta ao catálogo

Esta funcionalidade permitirá consultar os livros cadastrados no sistema Biblioempréstimo.

## Informações exibidas

- Título do livro.
- Autor.
- Editora.
- Ano de publicação.
- Disponibilidade para empréstimo.

A consulta ajudará os usuários a encontrar livros e verificar se estão disponíveis para empréstimo.
